# 🐾 Digital Pet App

An interactive virtual pet care application built with **React**, **TypeScript**, and **Vite** for my Chingu Tier 2 Solo Project.

## 🔗 Live Demo
[View Live App](YOUR_VERCEL_LINK_HERE)

## ✨ Features
- **Pet Customization:** Choose between a Dragon, Dog, or Cat and give your companion a custom name.
- **Real-Time Simulation:** Uses React `useEffect` timers to gradually decrease hunger, happiness, and energy over time.
- **Dynamic Moods & Visuals:** Pet reactions and color-coded progress bars update automatically based on stat levels.
- **Persistent State:** Automatically saves your pet's progress to `localStorage` so your companion stays safe across page refreshes.

## 🛠️ Tech Stack
- React 18
- TypeScript
- Vite
- CSS3

## 🚀 Run Locally
1. Clone the repository: `git clone https://github.com`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
